WHAT TO PORT, IN ORDER
  1. MAZE — the 31 × 28 tile map. Characters: # wall, . dot, o pellet, - gate, H house, space = void. Copy it byte-for-byte into a [31][]const u8.
  2. resolveWalls() — open-side → glyph. Run once at level load into [31][28][]const u8. Out-of-bounds counts as OPEN, which is what gives the outer border its corners.
  3. layout(cols, rows) — returns mode, cells-per-tile, rail width, x/y offsets. Pure function, no state, called on winsize only.
  4. draw*() — HUD, maze, entities, rail, overlay. Each takes (state, window) and writes cells. No allocation.
  5. step(dt) — fixed 120 Hz: input buffer → pac → ghosts → collisions → phase machine.
