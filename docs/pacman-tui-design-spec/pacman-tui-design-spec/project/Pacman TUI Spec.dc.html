READING THE MAZE
  • Wall tiles are line glyphs resolved from neighbours (11 cases: ╭ ╮ ╰ ╯ ─ │ ├ ┤ ┬ ┴ ┼), rounded corners only. A wall is never a filled block — filled blocks read as walls-are-rooms and kill the arcade look.
  • Corridor interiors of wall structures stay black. The eye completes the shape.
  • The tunnel row (maze row 15) has no side wall: Pac and ghosts wrap x, ghosts at half speed inside it.
  • Ghost-house door is ╌╌ in pink, non-collidable for ghosts only.
  • HUD is unframed text on rows 0–1 and row 33 — same left margin as the maze wall, never boxed.

Center with saturating integer math — (root.width -| 28) / 2 — and bias odd remainders left. Recompute only on winsize events. Wide mode doubles every wall glyph horizontally (line glyphs with a horizontal arm pair with ─, pure verticals pair with a space) so corridors stay connected and tiles read square.
03 — Palette

modern_palette

Arcade hues, terminal luminance. Two roles are deliberately brighter than the original — walls and frightened ghosts — because #2121DE on black is 2.5:1 and unreadable on a dim laptop panel. Everything is measured against #000000.

CONTRAST & ACCESSIBILITY
  • Shipping palette: every foreground ≥ 4.5:1 on black. Blinky (5.3) and walls (4.6) are the floor — never dim them, never draw them on a non-black bg.
  • Offer --theme=arcade for the authentic #2121DE walls, opt-in and documented as low contrast.
  • Nothing is signalled by hue alone: frightened ghosts also flash, eaten ghosts change glyph, Pac's mouth stops when blocked, dots-remaining has a numeric readout in wide mode.
  • Blinky/Clyde is the weak pair under deuteranopia — they never share a row in the HUD roster, and the roster labels them by name.
  • Never set bg on maze cells: inherit the terminal background so transparency and user themes survive. Only HUD inversion and overlay cards paint bg.
  • Dots are peach, not white — white is reserved for ghost eyes, HUD values and the frightened flash, so three separate meanings never collide.
// palette.zig const vaxis = @import("vaxis"); const Color = vaxis.Cell.Color; // Color = union(enum){ default, index: u8, rgb: [3]u8 } pub const Role = struct { rgb: Color, idx: Color }; fn role(hex: u24, i: u8) Role { return .{ .rgb = Color.rgbFromUint(hex), .idx = .{ .index = i } }; } pub const modern_palette = struct { pub const wall = role(0x3B4CFF, 63); pub const gate = role(0xFFB8FF, 219); pub const dot = role(0xFFB8AE, 224); pub const pac = role(0xFFFF00, 226); pub const blinky = role(0xFF0000, 196); pub const pinky = role(0xFFB8FF, 219); pub const inky = role(0x00FFFF, 51); pub const clyde = role(0xFFB852, 215); pub const afraid = role(0x3B4CFF, 63); pub const flash = role(0xFFFFFF, 231); pub const hud = role(0xFFFFFF, 231); pub const hud_dim = role(0x9EA4B8, 248); }; // resolve once, at startup — not per cell pub fn fg(vx: *const vaxis.Vaxis, r: Role) Color { return if (vx.caps.rgb) r.rgb else r.idx; }
04 — Typography & glyphs

Glyph reference

Every glyph here is width-1 in a modern monospace terminal. No emoji. 🟡 is width-2 in most terminals and width-1 in a few — a single mismeasured cell shears the whole maze. Measure with win.gwidth() at startup and fall back to the ASCII column if any glyph reports ≠ 1.

05 — Animation & state

Cadence

One fixed-step sim clock at 120 Hz, render capped at 30 fps and only when the frame changed. Movement is tile-quantised, so there is no easing anywhere — sub-cell interpolation just aliases into neighbouring cells. Feel comes from timing and from the input buffer, not curves.

scatter chase scatter chase …
██████████████████ frightened · flash @ 4 Hz
Frightened pauses the mode clock and resumes it on expiry. Every mode edge forces a reversal — that is the tell players read as “the ghosts changed their mind”.
AnimationState — what it owns
  • One monotonic tick: u64. Every cycle is tick % period — no per-entity timers, no drift, trivially seekable for tests.
  • Phase accessors only: mouthOpen(), pelletVisible(), frightFlash(), deathFrame(), mazeFlash().
  • Cutscene lock: while .ready, .death or .cleared runs, Game skips input and AI but keeps ticking.
  • Input buffer belongs to Game, not here: hold the last direction key for 250 ms and apply it the instant the tile ahead opens. This single rule is most of what makes the game feel arcade-tight.
  • Never use the SGR blink attribute for pellets or flashes — terminal support is inconsistent and the rate is not yours to set.
